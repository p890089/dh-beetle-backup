Personal backup utility · 個人備份工具

DH Beetle Studio Backup

一套供 DH Beetle Studio 擁有者個人使用的加密備份流程，目的是將已加密的資料庫備份副本安全儲存到自己的 Google Drive。

A personal-use encrypted backup workflow for the owner of DH Beetle Studio. It stores encrypted backup files in the owner's own Google Drive account for recovery purposes.

運作方式 · How it works

  • 在使用者自己的 Windows 電腦上，使用 restic 加密備份資料。 Backup content is encrypted locally with restic before off-site transfer.
  • 使用 rclone 連線至使用者自己的 Google Drive。 rclone connects to the owner's Google Drive account.
  • 要求 Google Drive drive.file 權限，供工具管理它建立或使用者選取授權的特定檔案。 Only the drive.file Drive scope is requested for files authorized for this application.
  • Google OAuth 憑證由使用者本機保管；備份解密密碼不會作為雲端備份一起上傳。 OAuth credentials remain on the owner's device, and the backup decryption password is kept separate from cloud backups.

使用對象 · Intended users

這是個人自行管理的備份工具，並非開放註冊的商業雲端儲存服務。OAuth 授權只應由已知的帳號擁有者進行。

This is a self-managed tool for personal use, not a public backup service or a product accepting registrations.

資料安全 · Data security

這個網站只提供說明文件，不提供登入、備份檔案上傳或金鑰輸入功能。Google Drive 上的實際備份是獨立的加密檔案；此網站不會要求或收集復原密碼。

This informational website does not accept uploads, account sign-ins, recovery passwords, or OAuth tokens. The backup operations run separately on the owner's own computer.

使用條款 · Terms of use

此工具僅供 DH Beetle Studio 擁有者個人使用。使用者自行管理 Google OAuth 授權、備份目的地及獨立保存的解密密碼；本說明網站不提供代管還原或復原密碼保管服務。使用前應自行確認備份完整性與還原能力。

This self-managed tool is intended solely for the owner's personal backups. The owner controls Google OAuth authorization, backup destinations, and a separately stored recovery password. This informational website provides no hosted recovery service or key custody. Backup integrity and restoration should be verified independently.
