隱私權政策 / Privacy Policy

本政策說明 DH Beetle Studio Backup 如何在擁有者自己的 Windows 電腦與 Google Drive 帳號間處理加密備份資料。

This policy describes how the owner-operated DH Beetle Studio Backup workflow handles encrypted backups through the owner's Windows computer and Google Drive account.

最後更新 / Last updated: 2026-10-08

1. 存取資料 / Data accessed

此工具使用 rclone 與使用者明確授權的 Google Drive 帳號連線。預定要求的 Google Drive 權限為 https://www.googleapis.com/auth/drive.file，僅處理此應用程式建立或使用者授權給此應用程式的特定檔案。操作期間可能接觸備份檔案內容、檔名、大小、時間戳記及其相關中繼資料。

The workflow uses rclone with the owner's authorized Google Drive account and requests the drive.file permission. It may process the encrypted file contents and related metadata (such as names, sizes and timestamps) for files created by or explicitly authorized for the application.

2. 使用目的 / Use of data

Google Drive 存取權只用於備份加密檔案、檢查備份清單與完整性，以及在使用者要求時還原資料。這些資料不會用於廣告、行銷、使用者側寫或出售。

Google Drive access is used only to store encrypted backup objects, inspect backup inventories or integrity, and restore data when requested. It is not used for advertising, marketing, profiling, or sale.

3. 儲存與加密 / Storage and encryption

備份資料在 Windows 裝置上透過 restic 加密，再傳輸至使用者自己的 Google Drive。Google Drive 會儲存加密後的備份物件及運作所需的檔案中繼資料。解密備份所需的復原密碼不會與雲端備份上傳至同一資料夾。

Backups are encrypted locally with restic before transfer. Google Drive stores encrypted repository objects and associated file metadata. The restic recovery password is not uploaded alongside those backup objects.

Google OAuth Client ID、Client Secret 及授權 token 由使用者在自己的 Windows 電腦上透過受保護的 rclone 設定保管，不由此公開說明網站收集或儲存。

OAuth client credentials and tokens are held locally in the owner's protected rclone configuration; this public informational website does not collect or store them.

4. 分享與第三方 / Sharing and third parties

此工具不會主動公開分享 Google Drive 備份，也不會將使用者 Google Drive 資料出售或傳送給廣告業者。Google 作為使用者選擇的雲端儲存服務提供者，會依其服務條款及隱私政策處理儲存與傳輸作業。此說明網站由 GitHub Pages 代管，但不提供 OAuth 登入、上傳或備份資料存取服務。

The workflow does not create public sharing links or sell Google Drive data. Google provides the selected storage infrastructure and processes data under its own terms and policies. GitHub Pages hosts this informational website only; the website has no login, upload, or backup access endpoint.

5. 保留及刪除 / Retention and deletion

加密備份會保留在使用者自己的 Google Drive，直到使用者自行刪除或明確核准備份保留／清理政策。此工具不會因撤銷 OAuth 授權而自動刪除既有雲端檔案。使用者可從 Google 帳戶安全性設定撤銷本工具存取權，並自行從 Google Drive 刪除備份資料。

Encrypted backups remain in the owner's Google Drive until the owner deletes them or expressly approves an automated retention policy. Revoking OAuth access does not itself delete existing files. The owner may revoke this app's access in Google Account settings and delete backup objects in Google Drive.

6. 本網站與分析 / This informational website

此網站是靜態 HTML，未加入追蹤指令碼、分析工具、登入表單或 cookie 功能。網站代管服務可能依自己的政策保留一般連線紀錄。

This website consists of static HTML and includes no application-added analytics, tracking scripts, login forms, or cookies. The website hosting provider may keep standard access logs under its own policies.

7. 聯絡及政策變更 / Contact and updates

如需聯絡工具擁有者，請透過 GitHub 帳號 p890089。本政策可能隨備份設計變更而更新，最新版本會公布於本網站。

For questions, contact the owner via GitHub p890089. This policy may be revised if the backup workflow changes; the current version will be posted on this website.
